# Editing guide for board members

## Change words on a page
Pages → open the page → Edit with Elementor → click the text → type. Update. That is all.

## Placeholder text
Anything shown with a striped background and a "Placeholder copy" label is filler. Replace it with real copy; the striped
styling disappears when the paragraph no longer carries the `is-placeholder` class (in Elementor: select the text, Advanced → CSS Classes, remove it).

## Add a resource card
Open the page, find the card grid (HTML widget), and duplicate one `<article class="card">…</article>` block. Or, better: add
the resource under Dashboard → Resources with its Approach, Topic, URL and Price, then swap the HTML widget for the "FaHa Resource cards" widget filtered to that approach.

## Add a board member
Dashboard → Board members → Add. Title = name, Role = position, featured image = headshot (square, at least 600×600). Set Order.
The About page's board grid updates when it uses the "FaHa Board grid" widget.

## Add a video
Drop the "FaHa Video (click to play)" widget and paste a YouTube link. It never autoplays and only loads YouTube after a click.

## Add a Zeffy or Google form
Drop the "FaHa Lazy embed" widget and paste the embed URL. Visitors see a button; the form loads when they click it.

## Rules of thumb
- One idea per section, one call to action per section.
- Say what it costs. Every resource has a price line.
- Never upload video to the site. Link YouTube through the video widget.
- Photos: check with the caregivers before posting (Group Rules → Private).
